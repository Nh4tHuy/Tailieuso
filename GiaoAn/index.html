AI Viết Giáo Án Mầm Non

Chào mừng WIKYAI - Soạn Giảng!

Tự động biên soạn KHGD Chủ Đề, Tuần & Giáo Án Chi Tiết Ngày theo mẫu Mầm Non Mỹ An.

Quy trình chuẩn 3 bước tạo giáo án:
  1. Tại Widget bên phải phần 1. Thiết Lập Giáo Án chọn và điền thông tin cần thiết.
  2. Tại Widget bên phải phần 2. Tải Tệp Kế Hoạch nhấp vào khung để tải lên dữ liệu cho AI (Bắt buộc).
  3. Chọn câu lệnh từ nút ✨ Lệnh Nhanh hoặc gõ yêu cầu cần làm.

Cấu Hình Gemini API Key

Nhập khóa Google Gemini API để kết nối trí tuệ nhân tạo.

Hướng Dẫn Lấy Gemini API Key Miễn Phí

  1. Truy cập Google AI Studio: https://aistudio.google.com/app/apikey
  2. Đăng nhập bằng tài khoản Google (Gmail) của Cô giáo.
  3. Bấm nút "Create API Key" → Sao chép chuỗi ký tự API Key.
  4. Dán chuỗi API Key vào ô nhập phía trên và bấm "Lưu Thiết Lập".

Hướng Dẫn Quy Trình Sử Dụng AI Viết Giáo Án

1 Thiết Lập Lớp Học & Tải Tệp Kế Hoạch (Widget 1 & 2)

Chọn độ tuổi, tên chủ đề, phương pháp tích hợp ở Widget 1. Sau đó bấm Widget 2 để tải tệp kế hoạch mẫu (.doc, .docx, .pdf, .txt).

2 Chọn Lệnh Nhanh Hoặc Nhập Yêu Cầu

Bấm nút ✨ Lệnh Nhanh ở ô nhập để chọn nhanh câu lệnh mẫu (Tạo KHGD Chủ Đề, Tuần 1, Giáo Án Chi Tiết...) hoặc tự gõ câu lệnh.

3 Nhận Kết Quả & Viết Tiếp Các Ngày/Tuần

AI sẽ phản hồi theo cấu trúc bài mẫu. Sau bài viết đầu tiên, menu ✨ Lệnh Nhanh sẽ xuất hiện thêm nút "Viết tiếp tuần tiếp theo" hoặc "Viết tiếp ngày tiếp theo".
